# Bark Ends

---

*Trees grow with bark on their ends.*

In vanilla Minecraft every log shows its cut rings on both ends, so the top of every trunk and the tip of every branch looks as if it has been sawn off. With Bark Ends, wherever the end of a log would be visible, it becomes the all-bark wood block instead. The logs inside the trunk stay normal logs, so stripping, chopping and building work exactly as they always have.

## Works with every tree

Vanilla trees, nether fungi and trees added by other mods all get bark ends, as long as their logs follow the usual naming where each log has a matching wood block. The change applies to trees that generate in new chunks and to trees you grow from saplings, while chunks you have already explored are left as they are.

Bark Ends adds no blocks of its own and only uses the wood blocks the game already has, so it is **safe to add to an existing world or remove again at any time**.

## For modpack and datapack makers

If a particular tree looks better with its normal log ends, add that log to the block tag `barkends:keeps_log_ends` and it will be left alone. The bark decorator can also be used directly in custom tree features as `barkends:bark_ends`.
